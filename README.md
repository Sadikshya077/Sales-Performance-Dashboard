# 📊 Sales Performance Dashboard

An end-to-end Data Analysis project demonstrating the complete workflow of cleaning, analyzing, querying, and visualizing sales data using Python, SQL, SQLite, and Power BI.

---

## 🚀 Project Objective

The objective of this project is to analyze retail sales data to generate actionable business insights through data cleaning, SQL analysis, and interactive dashboards.

This project is being developed over four days while learning industry-standard data analysis tools and best practices.
